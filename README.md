# Business Intelligence — 2026-II

Course repository for Business Intelligence, second semester 2026. Tuesday/Thursday sessions.

## Overview

Hands-on BI course progressing through a full analytics stack, using real-world datasets (Colombian open data) rather than synthetic examples:

1. **Power Query & ETL** — data extraction, cleaning, transformation
2. **DAX & Power Pivot** — data modeling, measures, calculated columns
3. **Storytelling & Dashboard Design** — visual design principles, narrative structure
4. **Power BI** — end-to-end semantic models and reports

## Repository Structure

```
├── schedule/           # Full semester schedule
├── slides/             # Adapted PowerPoint presentations per session
├── exercises/          # In-class exercise guides
├── exams/              # DAX exam materials and rubrics
├── final-project/       # Final project brief and requirements
├── datasets/           # Source datasets used in class
└── README.md
```

## Tools

- Excel (Power Query, Power Pivot)
- Power BI Desktop
- DAX Studio

## Prerequisites

Basic Excel proficiency. No prior BI or DAX experience required.
